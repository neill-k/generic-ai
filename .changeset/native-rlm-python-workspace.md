Add `@generic-ai/rlm`, a persistent Python workspace borrowed from Prime Agent's RLM: one `python` tool whose interpreter keeps variables for the whole session, with `rlm.llm` and `rlm.llm_batch` for sub-model calls from code, `rlm.tool` for the agent's other tools, timeouts and interrupts, and snapshot and restore. Native sessions and the native harness take an `rlm` option.
